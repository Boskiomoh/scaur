How this store was built

Scaur is a headless Shopify storefront for a fictional brand of mountain clothing, sold as a layering system. Products, prices, stock and the checkout come from a real Shopify development store. A portfolio project by Daniel Omoyibo.

Two ideas of its own

Thermal view Any product photo flips into an illustrative thermal image, and every piece is rated on one temperature scale from -10 to 80°F, so you see what a layer is for.
Kit builder Pick the activity, temperature, rain and wind. The rules choose one piece per layer, skip what isn't needed, and the whole kit goes into the cart in one action.

The stack

FrameworkNext.js 16 with the App Router, Server Components and Server Actions; React 19; TypeScript in strict mode.
CommerceShopify Storefront API on a development store, called from the server with a private token. No Shopify SDK: one typed fetch wrapper.
Data checksEvery URL parameter and cart request is checked on the server.
StylingTailwind CSS v4, with the design's colours, type and spacing as tokens.
TestsVitest for the kit rules and the catalogue parser; Playwright end-to-end tests with an axe accessibility check on every page.
HostingVercel Hobby. No paid apps or services: it costs $0 a month to run.

What it doesn't do

  • No real payments or shipping. Checkout runs in Shopify's test mode.
  • No customer accounts, wishlists or subscriptions.
  • No reviews, ratings or customer counts: nothing here pretends to be real.
  • Thermal views and temperature ratings are illustrative, not lab results.
  • Not indexed by search engines, because Scaur isn't a real shop.
  • No custom checkout: Shopify's hosted checkout is used, as it should be.
